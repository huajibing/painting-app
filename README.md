# Painting App

This is a lightweight painting application built with OpenGL & Dear ImGui.

## Quick Start

For a quick start, you're recommended to build with [xmake](https://github.com/xmake-io/xmake).

1. Clone repository

```bash
git clone https://github.com/huajibing/painting-app.git
cd painting-app
```

2. Install requirements

```bash
xmake require
```

3. Compile

```bash
xmake build
```

4. Run

```bash
xmake run
```
